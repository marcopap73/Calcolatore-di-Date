# Calcolatore di Date

Web app che calcola la data esatta dopo un certo numero di giorni (30, 60, 90…) a partire da una data scelta.

Il giorno di partenza non si conta: il conteggio comincia dal giorno successivo. Si possono escludere dal conteggio:

- sabati e domeniche
- il mese di agosto
- le festività nazionali italiane (con Pasqua e Lunedì dell'Angelo)

Funziona nel browser, da computer e da telefono, senza installare nulla.

**Usa l'app:** https://marcopap73.github.io/Calcolatore-di-Date/
